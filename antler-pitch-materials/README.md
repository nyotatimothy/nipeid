## 🖨️ How to Generate PDFs

### Method 1: Browser Print (Recommended)
1. Open any HTML file in Chrome or Safari
2. Press `Ctrl+P` (Windows) or `Cmd+P` (Mac)
3. Select "Save as PDF" as destination
4. Choose "More settings" and select "Background graphics"
5. Set margins to "Minimum" for best layout
6. Click "Save"

### Method 2: Developer Tools (Advanced)
1. Open browser Developer Tools (F12)
2. Toggle device toolbar and select "Print"
3. Use "Capture screenshot" for high-quality images
4. Combine screenshots into PDF using online tools
